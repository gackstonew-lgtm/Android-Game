# Assets Directory Structure
This folder contains runtime assets for Chase:
- `models/cars/`: 3D player and pursuer vehicles
- `models/props/`: Street props, obstacles, traffic vehicles
- `models/environments/`: Track pieces, buildings, scenery
- `models/drivers/`: Cockpit and driver models
- `textures/`: Texture maps and atlas sprites
- `audio/sounds/`: SFX (engine, screech, sirens, crashes, UI)
- `audio/music/`: Background pursuit music tracks
- `particles/`: Particle system definitions
- `ui/`: Skins, icons, fonts
- `data/`: JSON definitions for cars, environments, upgrades
